# 水世代 · 第一层 Three.js Demo

2026-10-03：已实现五次航行的第一版可玩循环，无 Boss。沿用原来的海面、木筏和界面布局，加入简单开始界面、随机种子、真实物资/AP、四航道战斗、合成、生产、战损修补、轮末弃牌与通关/失败页面。

## 本地运行

在本目录执行 `npm start`，或 `python -m http.server 5173 --bind 127.0.0.1 --directory dist`，打开 http://127.0.0.1:5173/ 。也可运行原有 `启动预览.cmd`。Three.js r180 已保存在 `dist/vendor`；无需安装 npm 依赖或访问 CDN，需要支持 WebGL 2 的现代浏览器。

## 试玩

1. 开始界面可输入种子，点击“开始航行”。默认种子 20261003。
2. 选择补给，在准备阶段点击手牌使用或从左侧合成台制作，选择一个候选并提交航行。
3. 事件按分支处理；战斗点击手牌选目标或部署设备，查看意图后结束战斗回合。第二回合起可撤退。
4. 每次航行结算饥渴和生产，超出十张时点击手牌弃置。第五次航行结算及弃牌完成后通关；生命归零失败。

“木筏”面板管理设备、生产领取、移动与战损；“说明”查看操作和规则，“日志”查看费用与结算。开始界面明确提示：**没有浏览器存档，刷新会重开**。不要沿用旧版数字键/固定探索点操作。

## 实现与验证

- `dist/game/`：独立 ES Module 规则；`content/catalog.js` 定义 24 张首版卡、8 配方、3 普通怪物、12 节点及试测参数；`session.js` 是事务式命令入口。
- `dist/app.js` 与 `demo.css`：DOM 展示与交互；`scene.js` 组合场景，接收只读视图，不持有规则状态。
- `dist/presentation/`：C/N/M 图片显式映射、程序化木筏及四种设备模型；模型与 GPU 对象不进入游戏状态。
- `dist/assets/manifest.json`：运行资产登记；`asset-sources/`：原始 ZIP、制作源和程序化资产说明。
- `npm run check` 检查脚本语法；`npm test` 运行规则与模型测试；`npm run check:assets` 检查资源 ID、文件、哈希、尺寸和全部 C/N/M 映射。

实际结果、浏览器种子路线、试测决策与限制见 [首版验收记录](../docs/development/first-layer-demo-v1.md)。测试日志及实际截图位于 `evidence/`。这版已完成基本循环，不代表数值平衡、所有内容逐项视觉验收或性能优化完成。
