# 2026-10-03 修订：涌泉抽牌与行动结束

当前第一层默认值与相关行为由 [平衡试测 v5](first-layer-balance.md) 补充覆盖：初始饥渴 40、低风险保底、属性战术攻击、前置设施与临时防卫销毁；内容版本 first-layer-v4。下文旧版本及旧数值用于追溯。

依据最新用户指示：右侧红色涌泉每次航行可抽三张随机卡；仅行动点耗尽或主动结束后弃牌。此修订优先于首版旧的“一张选择、两张随机”补给机制；N03 航行候选仍为独立的三选一事件，不与场景常驻涌泉混同。战斗战术补给仍是临时牌二选一。

## 已实现接口与流程

新增 DrawSpring（仅 VoyageSupply，0 AP，一次发放三张）；新增 VoyageAction 阶段和 EndVoyageAction 命令。createSession 的 contentVersion=first-layer-v2，随机算法仍 lcg32-v1。进入每轮时由 supply 随机流提前固定三张，视图仅返回数量，不暴露结果；DrawSpring 领取而不再抽随机数。预览/拒绝/恢复/界面动画不会重掷；重复抽取原子拒绝。

航行：涌泉抽牌 → 航行准备 → 选择候选并处理节点 → 剩余行动 → 结算 → 超限弃牌 → 下一次涌泉。节点奖励或战斗胜利本身不代表主动结束：还有 AP 时留在 VoyageAction，可吃喝、制作、部署、维修、移动、领取产物，不能再选节点或使用航行干预牌。点击“结束行动”即放弃剩余行动机会；AP 耗尽则自动结束。航行准备 AP 已耗尽时仍必须选择并处理一个节点，然后自动结算，不能提前弃牌跳过节点。无超限时跳过弃牌。

战斗行动 AP 到 0 或主动“结束战斗回合” → 设备攻击/敌人意图/深潮 → 超限弃牌 → 下回合战术补给。敌人直接全灭时，若尚有 AP 则进入 VoyageAction，不再执行敌方攻击；剩余 AP 耗尽或主动结束才进行本航行饥渴/老化/生产/弃牌。生命归零即时失败，不强迫再结束。仍先老化后生产，一次航行只结算一次。
