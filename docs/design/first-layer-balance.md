# 第一层平衡试测 v5

日期：2026-10-03。用户授权依据前次平衡评估优化当前 Demo。本文件覆盖旧文档中对应的默认数值、补给保底和战术池；全部调整属于改版试测设计，不冒充原始规则或此前讨论确认。当前 contentVersion 为 `first-layer-v4`，浏览器规则缓存标记 `balance-v5`。

## 目标与具体改动

保留五次航行、3 AP、免费三张涌泉、十张手牌上限、每航行轮饱食/水分各 -10、筏格损伤与两轮老化。初始饱食/水分由 80 改为 40，SAN 仍为 80。起手干粮与淡水分别 +24；正确使用各一张能在无其他消耗的五轮路线中保持生命 30、最后饥渴各 14。全程不吃喝会在第四、第五轮各受 4 生命损失，最终生命 22；作为教学层仍允许带伤通关，不声称杜绝安全通关。

| 项目 | 当前试测行为 |
|---|---|
| M02 水母 | 4 生命，火把 3 伤害，通常需战术补刀 |
| M03 蟹 | 5 生命，放电 4 伤害；海水可以施加浸湿，随后放电 +1，可用两张牌速胜 |
| 战术补给 | 第 2 回合起盾 T01 与敌人对应攻击二选一：M01→T02 材料、M02→T03 热源、M03→T04 能量；攻击均 1 AP / 2 伤害 |
| T03/T04 | 新增临时火种/临时电弧；不能合成永久物资，战后清除；独立于素材包 T 材料图标编号 |
| 临时防卫 | C18/T01 被击毁后立即移除、释放槽位；永久轻弩仍留下残骸，不改变修复/重建费用 |
| 首轮候选 | 若池中存在且尚未领取，保底 N04 工具箱 |
| 后续候选 | 保底低风险 N01/N02/N03/N08/N10/N12 中一个合格节点；低风险允许零奖励，无每轮补给保证 |
| N04 | 领取后移出候选池；未领取可在后续随机出现，后续不再固定保底 |
| 设施时机 | 第二轮候选保底 N09（若配置池包含它），与低风险候选同时提供；第四轮起排除 N09，N03 也不再提供 C20/C21 |
| N11 | 两组选项均先受随机外围一格轻损伤：废铁＋蓄电碎片＋漂流木，或废铁＋蓄电碎片＋淡水＋干粮；锚取消损伤 |

战术攻击由当前存活敌人确定。首版一个战斗只含同一种怪物，故不引入混合怪物选择或新的随机流。预览、恢复、拒绝均不重掷；临时牌不会生成永久物资。海水施加状态与攻击伤害的限制显式区分：只有 M03 新增浸湿例外，水母仍拒绝海水，能量进攻门槛不变。

设施生产仍为每两轮一次、容量一，不改终局结算：第五轮结算后的产物不能领取。通过前置机会改善回报，不伪造终局收益或添加第六轮。导航工具和战斗 AP 刷新仍按既有契约处理。

## 配置、保存与显示

catalog CONFIG 新增 `initialHunger/initialHydration`、`lowRiskNodes`、`facilityOpportunityVoyage`、`facilityLastVoyage`、`tacticalAttacks`。默认设施机会为第 2 轮，最后奖励轮为第 3 轮。测试池未包含 N09 时不强行加入；N03 默认三选一，自定义不足三种奖励时只提供池中不同的卡，采用有限的不放回抽样避免卡死；保底列表没有合格条目时回退池内非战斗节点，并仍要求至少两种合格节点。

状态形状不变，配置随保存持久化；内容版本从 first-layer-v3 升至 first-layer-v4，旧版本直接拒绝，不自动迁移。schemaVersion=1 和随机算法 lcg32-v1 不变。仍无浏览器存档/继续功能。

手牌、战术选择、玩法指南与目标按钮同步显示新效果。T03/T04 暂复用 C13/C14 原图，卡名、材料、费用与效果以实时文字为准，资产映射见 [源记录](../../water-era/asset-sources/balance-v5.md)。

## 验证与尚待观察

固定种子测试覆盖饮食与零消费完整五轮、属性怪物无永久攻击时获胜、临时牌恢复/预览不重掷与不可合成、浸湿速胜、节点保底/领取移池/晚期奖励、漩涡两组选项与锚保护、临时盾销毁和永久残骸。实际结果见 [验证记录](../../water-era/evidence/balance-v5-verification.md)。

`scripts/balance-sim.mjs` 通过公开 GameSession 命令运行种子 1–100 的两种非战斗策略，结果保存在 evidence/balance-v5-simulation.json。它只比较第一可用低风险路线、末尾弃牌、不建设备的策略，不能当作真人难度或最优策略证明。

后续重点记录：实际战斗长度与生命代价、设施通关前的领取/饮食次数、风险节点选择比例、每局弃牌数量。安全路线仍容易通关、物资仍偏多、战斗 AP 拖延的后勤收益未调整；本轮不增加强制战斗、Boss、商店、扩建或负面藏品。
