# 筏格损伤与生存规则修订

当前第一层默认值与相关行为由 [平衡试测 v5](first-layer-balance.md) 补充覆盖：初始饥渴 40、低风险保底、属性战术攻击、前置设施与临时防卫销毁；内容版本 first-layer-v4。下文旧版本及旧数值用于追溯。

更新日期：2026-10-03。依据：用户提供的 2026-10-02 20:08–20:12 讨论，以及本次对设备和脱落时限的补充确认。当前开发目标仍为一层 Three.js Demo；本文件修订玩法，不表示代码已实现。

## 1. 已确认的规则

- 饱食、水分每个**航行轮**各减 10，低值更急迫；战斗回合仍不额外推进航行消耗。数值高表示健康，水分不是越高越危险的“口渴程度”。
- 取消整船耐久和船体 HP。角色生命与 SAN 保留；饱食或水分归零损失生命，怪物攻击可以造成生命、SAN 或筏格惩罚，必须按意图说明。
- 筏格采用 **完好 → 破损 → 脱落** 三态。“半格”描述破损状态，不是每个格子再加一条数值耐久。
- 轻惩罚令完好格破损；已破损格再次受轻惩罚则脱落。严重惩罚令目标格直接脱落。
- 对外围格随机选择目标，与扩充顺序无关。格子脱落后重新计算外围，不能一直使用开局的外围列表。
- 破损格不能放新东西，已有设备保留但停用，修补后恢复；格子脱落时，上面的设备、残骸及储存产物一并损失，不返还手牌或材料。
- 破损后经过 **2 个后续航行轮结算**仍未修补则脱落，这是已确认的首轮试测参数。受损当轮不计时，战斗回合不计时，再次受击立即脱落，不等待倒计时。

保留此前饥渴生命惩罚：饱食结算为 0 时生命 -2，水分为 0 时生命 -3，同轮合计封顶 4；这些数值没有在讨论中改动。生命归零失败，不再检查船体耐久归零。SAN 不默认每轮扣减，怪物精神攻击由预告意图给出。

## 2. 空间、占用与修补

物理筏格位置用于算外围和承载设备，和海域航行候选无关；不恢复网格航行、寻路、视野或旧 B 方案。四条航道仍是四条逻辑战线，防卫槽及后勤槽必须明确绑定承载格。只有承载格完好时才可部署、移动入位、交换入位、重建设备残骸、攻击、生产、领取产物或提供工具条件。

设备停用不把它的自身结构设为零，修补格子不恢复设备结构。格子修好后，原设备若仍有结构则恢复工作；结构为零的设备仍是残骸。单位受到单独针对设备的攻击时，按其自身结构处理，与筏格状态互不替代。

外围判定采用布局配置中的整数坐标与四邻接：未脱落格存在至少一个无未脱落邻格的相邻方向，则属于当前外围。这是程序设计决策，用于稳定复现讨论中的“外围一圈”。初始格数、布局和槽位绑定需在内容配置中明确，不把场景装饰木板数量自动当作规则格数。脱落格保留 ID 与位置记录，以便显示缺口。

受击随机目标来自当时有效外围池，按稳定 ID 排序后使用已保存随机流抽取；预告只公开“随机外围 1 格 + 轻/严重”，结算时才抽取具体格，预览和打开界面不能消耗随机数。无候选格时记录无目标，不悄悄转成角色伤害。

修补只对破损格生效，恢复完好并清除破损计时。**脱落格不能通过“修补”重新长回**；补建缺失格的费用、配方和初始布局未在讨论中确定，保留后续设计，不伪装成原维修卡功能。全筏格脱落是否有独立失败条件也待确认；本次只保留已明确的生命归零失败，不用隐含整船耐久替代该问题。

| C15 修补包 | 1 AP + 消耗牌，修好指定 1～2 个不同破损格；无目标不可使用 |

| M03 绝壳蟹 | 同道可工作防卫单位承受 2 结构攻击；无防卫时角色生命 -2 |

攻击/生命牌面数值仍表达单位交战的结构伤害与怪物生命。空道惩罚单独配置，不能把“2 攻”自动解释为扣 2 格或同时扣生命、SAN、筏格。群体惩罚按效果顺序逐格抽取，每次损伤后更新外围。

首版现在需要处理 SAN 归零：沿用整体规则的基础精神崩溃，生命 -6、SAN 回到 25，并立即检查死亡；从正值降到 0 触发一次。负面藏品、最大 SAN 衰减和第三次崩溃额外代价留在完整版，不扩入当前切片。单次同时造成生命与 SAN 损失的效果先应用全部损失，再检查生命败亡；已失败不通过回 SAN 复活。

## 4. 时序与验收

假设第 1 航行轮节点使格 A 破损，记录 damagedAtVoyage=1：第 1 轮结算不老化；第 2 轮结算累计 1；第 3 轮结算累计 2，仍未修好就脱落。如果第 2 轮行动时已修好，则取消倒计时；若第 2 轮又受轻损伤，则立即脱落。

航行轮末依次：饱食/水分各 -10 → 饥渴生命损失及败亡检查 → 破损格老化/脱落 → 鲜鱼腐坏 → 完好承载格上的设备生产 → 弃牌。这样到期脱落的设备不会再免费完成一次生产。暴雨奖励期间的生产同样先检查承载格完好。

需要后续实现验证：

- 饱食和水分 80，航行一次后均为 70；战斗持续多回合也只扣一次。
- 取消整船耐久 UI、字段、恢复效果和失败判断；设备结构仍存在。
- 同一格轻损伤两次脱落；严重一次脱落；已脱落格不再选为损伤目标。
- 破损后禁止新增占用，已有设备停攻/停产/停用工具；修格不回血，脱落不返还物资。
- 外围按当前布局重算，不优先损失最后扩充格；固定种子和重放得到相同目标。
- 损伤当轮不老化，两个后续航行轮后脱落，战斗回合不加速。
- 材料限定、防卫失效、角色生命/SAN 处罚、精神崩溃与终局次序均清楚预告并可复现。

历史 Unity 契约与旧开发日志保留原数值用于追溯，不能用作当前规则依据。当前有效架构、接口与数据模型必须引用本修订。
