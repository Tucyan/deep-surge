# 木筏状态展示（当前 v6）

2026-10-03。属于 Three.js 表现层调整，不新增扩建费用、扩建命令或设备槽位规则。

## 状态与模型映射

主场景从 GameSession.getView() 接收只读快照，createRaftPresenter.sync(view) 按 cells.id 对账：新增格创建板，删除格释放资源，坐标变化重新定位，完好/破损/脱落切换板状态。格距为 2.3×2.25；不再固定生成 12 块或使用跨缺口的外围框架。

每格文字由槽位 cellId 和单位 cellId 关联，显示坐标、角色、设备名称及结构；生产设备同时显示进度或储存物。破损格设备显示停用，结构为零显示残骸。脱落后板和拾取代理隐藏，只保留虚线缺口标签。当前规则脱落时删除设备及储存物，表现层不另作规则判断。点击在位格可查看名称和承载状态。

## 展示筏根与比例

筏根是一块 7.6×3.2 的独立装饰平台，有低帐篷、灯、箱、绳圈和渔网，不提供槽位、生产、存储或战斗能力。始终放在当前格子网格后方，不覆盖功能格；不写入 GameState，也不计入筏格数。功能设备暂用文字占位，原设备模型工厂保留。

按网格与筏根联合边界居中，整体缩放不超过 1.05，最大占用宽 10.6、深 10.2。扩展后等比缩小，保持现有 UI 区域可见；大型筏面文字可能变小，本次未增加镜头缩放/平移交互。

统计区分登记格、在位格、破损与脱落；扩展数量按初始 4×3 坐标窗口外的登记格统计，不是累计购买次数。游戏仍使用现有 12 格与四防卫/两后勤槽位。

## 2026-10-03：营地、透视与水面接触 v6

根区面积扩大约 3.35 倍，增加布面下垂与帐篷开口、床垫、板条箱框架、系泊绳桩、箍桶、垂挂菱形渔网和灯笼笼架。移除遮挡营地的根区文字牌，功能格文字和状态映射保留。12 格缩放约 1.01，20 格约 0.83。

主视角从正交改为 36° 轻侧视透视，降低俯视角，展示甲板厚度、帐篷侧面和箱体深度。镜头与窗口比例、鼠标偏移均由独立 camera.js 管理。

主游戏的木筏按海面相同波形采样升沉、俯仰和横摇，调整浮木水线，减少悬浮间隙。外缘白沫与接触暗边按在位格和筏根的联合外围生成，内部拼缝不生成，脱落后更新；泡沫网格在水面上随波起伏。关闭动态画面时停在固定姿态。属于运动学视觉表现，未实现刚体浮力。
